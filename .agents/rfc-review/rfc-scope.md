# Fundamental RFC reading map

This is a parsing-focused map, not an exhaustive email standards catalog.
Read the linked sections when their behavior is in scope. Verify applicable
updates and errata through each RFC's information page, for example
[RFC 5322 status](https://www.rfc-editor.org/info/rfc5322).

## Boundaries

Do not expand into SMTP delivery, IMAP/POP, JMAP, DNS, TLS, SPF, DKIM, DMARC,
S/MIME verification, or every registered MIME subtype by default. Outlook's
binary MSG format is not specified by these RFCs; evaluate the converted MIME
message and wrapper behavior, and disclose conversion dependencies.

Full assessments must address every applicable row above. Diff reviews address
only rows touched by the selected changes. Sections 2049 (MIME conformance and
examples) or other direct dependencies may clarify a disputed requirement, but
do not substitute a broad document citation for the exact operative paragraph.
